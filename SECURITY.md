# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use GitHub's private vulnerability reporting for this repository:
https://github.com/NovusKey-Labs/nibhaus/security/advisories/new

Reports are acknowledged within 7 days. Fixes ship as a normal release and the advisory is published once a fixed version is available.

## Scope

The Android app in `android/` (`:app`, `:pencore`, `:penble`, `:premiumapi`). Issues in the private `:premium` module go through the same channel.

## Supported versions

The latest release and the current `master` branch receive security fixes.
